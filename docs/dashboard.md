# ダッシュボード

Lunaの現在の状態と直近の出来事を示す、閲覧専用のWebページを定める。認証がないことの影響は [SPEC.md](./SPEC.md) の信頼境界の節にある。

## エンドポイント

Lunaは起動中常に、HTTP APIとは別のポートでダッシュボードを提供する。`GET /` はHTMLページ、`GET /api/snapshot` は現在の状態のJSONを返し、どちらもキャッシュさせない（`cache-control: no-store`）。ページは3秒ごとにスナップショットを取得して表示を更新する。それ以外のパスは `404`、スナップショット取得中の予期しない例外は `500 {"error":"internal_error"}` を返す。

## スナップショット

スナップショットは取得時点のメモリ上の状態であり、永続化しない。

| 項目            | 内容                                                                                                                                                                                                                                                               |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `agent`         | ChatGPTの認証状態（認証済み・再ログインが必要・未ログイン）、最新の使用枠、直近の障害、開いているエージェントのセッション（種類・ラベル・モデル・フェーズ・再試行回数）                                                                                            |
| `conversations` | 開いている会話セッションごとのフェーズとその開始時刻、未処理の入力件数、セッションID、再試行回数、モデル設定、待機中ならアイドル期限                                                                                                                               |
| `events`        | 実行中のワンショット実行（ハートビート・スケジュール・日次整理・タスク報告・HTTP）のイベント、フェーズ、開始時刻                                                                                                                                                   |
| `tasks`         | 実行枠の上限と使用数、未完了のタスクと終了から24時間以内のタスク（最新50件）の全内容                                                                                                                                                                               |
| `automation`    | ハートビートの次回発火時刻（実行中は持たない）、日次整理のcronと次回発火時刻、登録済みスケジュールジョブの定義と次回発火時刻                                                                                                                                       |
| `workspace`     | ワークスペースのあるファイルシステムの全容量と空き容量、ゴミ箱の日付フォルダごとの削除日と中身（直下の名前）                                                                                                                                                       |
| `homeAssistant` | HAの接続を設定していなければ `null`。設定していれば、WebSocketの接続状態（接続中・接続済み・再接続待ち）とその開始時刻、再接続の予定時刻、直近のエラー、`home-assistant.toml` の状態（なし・有効・不正）と内容または検証エラー、状態変化で起動した回数と最後の時刻 |
| `activity`      | 直近の出来事（info以上のログ）最大500件。`LOG_LEVEL` に関係なく本文（payload）を含み、詳細と本文はそれぞれ4000文字で切り詰める                                                                                                                                     |

## 内部設計

```text
ConversationCoordinator.snapshot ─┐
EventExecutor.snapshot ───────────┤
TaskService.snapshot ─────────────┤
AutomationService.snapshot ───────┼─► DashboardService.snapshot ─► GET /api/snapshot ─► ページ（3秒ごとに取得）
AgentRuntimePort.status ──────────┤
StateChangeWatcher.status ────────┤
RecentLogBuffer.list ─────────────┘
```

- 各モジュールはアプリケーション層に読み取り専用の `snapshot`（エージェントのアダプターは `status`）を持ち、状態の型はdomain/ports層に置く。`DashboardSourcePort` はそれらを呼ぶ関数の集まりで、コンポジションルートが配線する。状態の変更通知の仕組みは持たず、取得のたびにメモリ上の状態を読む。
- 直近の出来事は、標準出力のロガーと同じ呼び出しを受ける `RecentLogBuffer` が保持する。標準出力と違い `LOG_LEVEL` に関係なくinfo以上を本文付きで残すため、ログレベルを上げずに会話の中身を追える。秘匿フィールドのマスクは標準出力と同じ直列化を使う。
- ページは外部ライブラリを使わない単一のHTML文字列で、表示する文字列はすべて `textContent` で入れる。Discordの本文をHTMLとして解釈しないため。
